# SLOG example data

This directory contains measurements and derived artifacts used as
reproducible examples. The corresponding acquisition notes live under
[`docs/runs/`](../docs/runs/).

Raw `.slog` files are authoritative. CSV, HTML, and image outputs are derived
convenience artifacts and may be regenerated by the analysis tools.

## Privacy

A raw record contains stable DS18B20 ROM addresses. Treat those identifiers as
pseudonymous installation identifiers. Before publishing another record,
remove unrelated personal context and do not add exact location, occupant
identity, health information, or unnecessarily precise wall-clock details.
Publication must be deliberate; opening a record locally in the portal does
not imply consent to publish it.
