# Example run: 2026-08-16 session 1

This is the first recorded full sauna test of the eight-height logger. The
CRC-validated raw log is preserved at
[`data/2026-08-16-sauna/session-1.slog`](../../data/2026-08-16-sauna/session-1.slog),
and the requested main-chart PNG is included for convenient inspection. The
`.slog` remains the source of truth; CSV and HTML files are generated locally.

![Eight probe temperatures over observed time](../../data/2026-08-16-sauna/session-1-main-chart.png)

## Test context and timing

- The stove was lit before the recorded sauna use began.
- People entered the heated sauna at approximately 14:00 local time.
- Power was removed at approximately 15:25 local time, without asking the
  logger to close the session.
- The log contains relative times, not wall-clock timestamps. Relating its last
  sample to the reported 15:25 power removal estimates the 40 C trigger at
  about 13:55 and the beginning of the retained pre-trigger data at about
  13:45. These wall-clock values are estimates, not measurements stored in the
  file.

The data therefore does **not** support the concern that the logger waited
until people entered the fully heated sauna. Probe 1 was already above the
trigger threshold by the estimated trigger time. At approximately 14:00
(`t = 290 s`), probes 1 and 2 measured 48.38 C and 44.44 C respectively.

## Recorded result

- 540 samples at 10-second intervals
- 1:29:50 of retained observed data, including 9:50 before the trigger
- session state `interrupted`, as expected from USB power removal
- no continuation link and no unknown power gap inside this file
- all eight probes valid in every sample; no missing measurements
- external 32.768 kHz RTC crystal active throughout; no fallback observed
- highest reading 79.94 C at probe 1
- maximum top-to-bottom difference 41.81 C
- fitted vertical gradient up to 34.56 C/m
- no rapid-warming candidates under the current analysis heuristic

Probe 1 crossed 40 C 30 seconds before the confirmed trigger and probe 2
crossed 40 C 80 seconds after it. Probes 7 and 8 remained below 40 C for the
whole run. The large, persistent vertical difference is consistent with strong
thermal stratification across the 140 cm probe span.

The ESP32-C3 internal sensor ranged from 21.6 C to 47.6 C. This is useful as a
logger-health indicator but is not a calibrated ambient-temperature reading.

## Reproduce the analysis

Install the analysis dependencies, then regenerate the derived files:

```sh
.venv/bin/pip install -r requirements-analysis.txt
.venv/bin/python tools/logs.py report data/2026-08-16-sauna/session-1.slog
.venv/bin/python tools/logs.py export data/2026-08-16-sauna/session-1.slog data/2026-08-16-sauna/session-1.csv
.venv/bin/python tools/logs.py plot data/2026-08-16-sauna/session-1.slog data/2026-08-16-sauna/session-1.html
```

The generated HTML is intentionally not committed: it is self-contained and
about 5 MB because it embeds Plotly. It follows the browser's light or dark
color scheme and can always be regenerated from the raw log.
