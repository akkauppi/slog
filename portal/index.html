Stage 1 · Install firmware

Install the project firmware

Put the XIAO ESP32-C3 into BOOT mode, choose it in the browser, then review the bundled release before anything is written.

  1. Disconnect USB. Leave the probes and other wiring undisturbed.
  2. Hold BOOT and reconnect USB. Release BOOT after the computer detects the board.
  3. Choose the bootloader port. Close PlatformIO or any serial monitor first.
