Stage 1 · Install firmware

Install the project firmware

Put the XIAO ESP32-C3 into BOOT mode, choose it in the browser, then review the bundled release before anything is written.

  1. Disconnect USB. Leave the probes and other wiring undisturbed.
  2. Hold BOOT and reconnect USB. Release BOOT after the computer detects the board.
  3. Choose the bootloader port. Close PlatformIO or any serial monitor first.

      Write confirmation

      Install this verified release?

      The portal will write the bundled sauna logger firmware to the selected ESP32-C3. It will not erase the whole flash, and it will not accept a replacement file.

      Final check

      Save this probe order?

      The logger will store this order, read it back, and restart. Existing sauna records are not changed.

      Remove saved run

      Remove this run from the logger?

      Every segment has a verified local copy. The logger removes the newest segment first. If power is lost, older valid segments may remain.
